# Running the gateway: organizer steps

Generated by the `litellm-bedrock-gateway` skill for the gateway
`{{STACK}}`. Run these in a terminal, from this repository's folder. First,
every time:

```bash
source gateway.env
```

That is all an organizer with AWS access needs (sign in first if AWS says the
session expired). Without AWS access, set up once as described in
`docs/organizer-no-aws.md`; the commands below then work the same.

The gateway URL is in `secrets/gateway-url`, never in this repository's files:
it goes to people privately, with their key.

## Workshop sign-up on the JupyterHub

People on the hub run `{{HUB_COMMAND}}`, type a code you say in the room, and
get their own key: `ws-<hub username>`, ${{BUDGET}}, {{DAYS}} days. The
participant page is `docs/hub-quickstart.md`.

**Once per hub** (and again after the script changes or the gateway URL
changes), copy the script and the URL into the hub's shared folder:

```bash
cp hub/{{HUB_COMMAND}} {{HUB_ADMIN_DIR}}/
cp secrets/gateway-url {{HUB_ADMIN_DIR}}/{{HUB_COMMAND}}.url
```

Participants run it as `{{HUB_DIR}}/{{HUB_COMMAND}}`. Use a folder
participants can read but not change.

**When the workshop starts** (the code is not case-sensitive):

```bash
python scripts/workshop.py open --code whale-2026 --hours 4
python scripts/workshop.py status
python scripts/workshop.py close
```

`open` defaults to ${{BUDGET}} per key, {{DAYS}} days and at most
{{MAX_KEYS}} keys; `--budget`, `--days` and `--max` change them. Sign-up also
ends by itself after `--hours`. `status` lists who has a key. If someone lost
their key or took the wrong name, delete it and they can sign up again:

```bash
python scripts/keys.py delete ws-their-username
```

## Give someone a key by hand

```bash
python scripts/keys.py create someone --budget 5 --days 7
```

- `--budget` is in US dollars; `--days` is how long until it expires.
- Add `--models {{DEFAULT_MODEL}}` to limit which models it may use (default:
  all). `python scripts/keys.py models` lists them.

The key is saved to `secrets/someone.key` and not shown. Send it
**privately** (a direct message, not a shared channel or email list) together
with the gateway URL from `secrets/gateway-url` and
`docs/participant-quickstart.md`.

## Watch use and cost

```bash
python scripts/keys.py list
```

Spend appears about a minute after each request.

Or the **Admin UI**: `<gateway URL>/ui`, user `admin`. The password comes from
the installer, or, with AWS access:

```bash
aws ssm get-parameter --name /{{STACK}}/ui-password \
  --with-decryption --query Parameter.Value --output text
```

## Switch a key off or on, or delete it

```bash
python scripts/keys.py block someone
python scripts/keys.py unblock someone
python scripts/keys.py delete someone
```

## Installer only (needs AWS)

```bash
scripts/instance.sh stop     # about $5 a month while stopped
scripts/instance.sh start
scripts/deploy.sh            # after changing models.yaml or gateway.env
scripts/teardown.sh          # deletes everything, keys and spend included
```
